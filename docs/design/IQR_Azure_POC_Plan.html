Is Fabric IQ necessary? No — and here is the reasoning

Fabric IQ answers a different question than IQR does. IQR's loop — ingest → match → sentinel → checks → verify → adjudicate — needs grounded retrieval (how was this pattern judged before? what does this control expect?), and that is Foundry IQ's job, already live on the AI Search index. Fabric IQ adds a semantic ontology + analytics layer over operational data: "which controls trended pass-with-gaps across FY26?", "which preparer's packages carry the most sentinel anomalies?" That intelligence matters when dozens of controls run every period — not while a POC validates three.

The cost mechanics, since you asked about turning it on and off:

  • Fabric F-SKU capacities bill per second and can be paused from the portal — a paused F2 costs $0. Run it only during a demo and the bill is cents.
  • A separate 60-day Fabric trial capacity is free and burns no Azure credit at all — the right vehicle if you want to show Fabric IQ inside the POC window.
  • Zero rework later: verdicts and ledgers already land as JSON blobs. A OneLake shortcut reads those containers in place — no copy, no pipeline. Deferring Fabric IQ costs us nothing in future integration.

The architecture — what exists and what each part does

The three laws (everything descends from these)

Numbers are computed by deterministic Python, never by a model. A test fails if a model is invoked on any numeric path.
Every claim carries a resolvable evidence locator. The citation gate mechanically rejects anything else — 100% citation validity is a hard gate.
Same input produces the same verdict. Reproducibility binds the verdict and its evidence set; a live model may rephrase, never re-decide.

Hallucination is removed structurally, not by prompt-begging

  • Agents cannot state a fact they didn't get from a tool — the runtime, not the model, accumulates citations; every number in a finding is an echo of a tool result.
  • The blinded verifier re-performs every finding from citations alone — the executor's reasoning is structurally absent from its input type.
  • The citation gate rejects any claim whose locator doesn't resolve — before the verdict and again at pack assembly.
  • Honest missing: absent or unreadable evidence becomes a gap, never a pass. In live Foundry runs, model variance only ever produced extra gaps for humans — never a false pass.
  • Every document type is read deterministically: .xlsx/.xlsm/.xlsb, .docx (including a 184MB workbook embedded as OLE), .msg/.eml with nested ZIPs, screenshots via OCR — each fact addressable, each failure recorded, nothing silently skipped.

Human in the loop — two gates, both human-owned

Design gate: the Plan Compiler drafts; an SME pins tolerances, timezones and scope, and freezes the plan. The runtime refuses unapproved plans, so a human decides what is validated before anything runs.

Run gate: sentinel HIGH anomalies, verifier disagreements, and gaps land in the exception queue (Table exceptions, surfaced in the console's Governance tab). A human adjudicates each one; nothing auto-submits in Shadow mode. Final approval of a package stays with the reviewer — IQR hands them a fully cited pack, not a decision.

Continuous learning — governed, never silent

Every human adjudication is recorded as an exemplar with its rationale. An exemplar reaches the runtime path only through two locks: the five-gate regression eval must stay green with the exemplar included, and an SME signs the release. Accepted exemplars index into the Golden Library on iqr-knowledge, so the next package with the same pattern retrieves how it was judged before — and every override becomes a permanent regression case. Quality compounds; it cannot drift, because drift fails the eval.

Web app on Azure

The console (run a control, watch the live ledger, adjudicate exceptions, download packs) deploys to App Service F1 — the always-free tier: Linux, Python 3.12, uvicorn iqr.api.app:app. One non-negotiable before it leaves localhost: Easy Auth (Entra ID) switched on — free, one CLI command — because the console fronts real control evidence and has no auth of its own. Locked to your tenant, it costs $0 and is reachable from any browser.
